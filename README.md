# RM-808 Studio

Boîte à rythmes, synthé wavetable/FM et rack d'effets pilotables par le contrôleur iDance RM-808 (ou tout contrôleur MIDI) via Web MIDI.

- Dev : `npm install` puis `npm run dev` → http://localhost:3000
- Build : `npm run build` → `dist/`
- Navigateur : Chrome / Edge (Web MIDI). Sur iPad, utiliser un navigateur iOS compatible Web MIDI.
- Code : JavaScript ES modules natif dans `js/` (aucune dépendance d'exécution).
